# 修改文件清单

上游基线:mem0 官方仓库 `18021dd`(2026-08-05),插件版本 0.2.13。
本插件为独立实现 `mem0-rvaim` v0.3.0,目录结构与官方插件对齐(scripts/
skills/hooks 布局),云端依赖全部替换为本地实现。

## 新增文件(service/)

| 文件 | 职责 |
|---|---|
| `service/__init__.py` | 包定义,版本 0.3.0 |
| `service/daemon.py` | HTTP daemon:健康/召回/捕获/CRUD/统计/管理接口,认证、限流、优雅关闭 |
| `service/bootstrap.py` | 单实例文件锁、后台派生、健康探测、安全重启 |
| `service/client.py` | hooks 用的 daemon 客户端(尽力而为,不阻塞) |
| `service/config.py` | 数据目录、配置加载/合并、env 覆盖、本地身份 |
| `service/schemas.py` | Pydantic 请求模型(拒绝未知字段,防伪造) |
| `service/security.py` | Bearer Token、namespace 派生、hash、密钥打码 |
| `service/memory_engine.py` | Mem0 单例封装 + Qdrant Local 固定路径 + 写锁 + 降级 |
| `service/recall_engine.py` | 双 namespace 召回、融合、去重、token 预算 |
| `service/capture_engine.py` | 事实捕获(infer)+ 会话摘要(infer=false)管线 |
| `service/scope_router.py` | scope 分类(独立 LLM)+ 服务端 namespace 派生 |
| `service/transcript_reader.py` | 增量 JSONL 读取、事件哈希 |
| `service/state_store.py` | SQLite:workspace/session/游标/幂等/重试/状态 |
| `service/provider_factory.py` | LLM/Embedder 独立配置、OpenAI 兼容 chat 客户端 |
| `service/mcp_proxy.py` | stdio MCP Server(JSON-RPC),转发到 daemon |
| `service/migrations/__init__.py` | 状态库迁移占位(版本化) |
